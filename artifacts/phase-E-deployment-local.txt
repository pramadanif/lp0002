## A correction worth recording
  getProgramIds returns only LEZ's BUILT-IN programs (amm, authenticated_transfer, pinata,
  privacy_preserving_circuit, token). It is a name registry, not a list of deployed user
  programs, so a deployed program does NOT appear there. This does not affect the version
  fingerprint in docs/VERSIONS.md, which compared exactly those built-in programs.
